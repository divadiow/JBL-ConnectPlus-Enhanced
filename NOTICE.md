# Attribution and project status

JBL ConnectPlus Enhanced is an unofficial community project.

The implementation and protocol work were informed by:

- the GPL-licensed public source of `pembem22/connect-plus`;
- publicly discussed JBL Connect / Connect+ protocol behaviour;
- direct hardware testing against privately owned JBL Charge 3 and Charge 4 speakers.

The application has been reworked around a separate Android BLE session architecture, defensive protocol parser, hardware diagnostics and conservative safety boundaries.

No JBL firmware, signing material, proprietary application assets or confidential Harman documentation are included.
