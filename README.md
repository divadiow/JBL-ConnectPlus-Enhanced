# JBL ConnectPlus Enhanced

An unofficial, open-source Android controller for older JBL **Connect** and **Connect+** speakers, currently focused on:

- JBL Charge 3
- JBL Charge 4
- JBL Flip 3
- JBL Flip 4

The current development build is **0.1.1-test2**. It is intentionally conservative: firmware flashing is excluded while BLE control and diagnostics are stabilised on real hardware.

## Download

The current hardware-test APK is committed at:

[`dist/ConnectPlusEnhanced-v0.1.1-test2-debug.apk`](dist/ConnectPlusEnhanced-v0.1.1-test2-debug.apk)

It is a debug-signed test build with package name `uk.co.divadiow.connectplusx.debug`. Check its SHA-256 against [`dist/SHA256SUMS.txt`](dist/SHA256SUMS.txt) before installation.

## Improvements over the original proof of concept

- Independent GATT state machine and serial operation queue for each speaker.
- Operation watchdogs, bounded retries and cancellable reconnect backoff.
- Compatibility paths for both newer CCCD-based notification setup and older CSR speakers that expose no CCCD.
- Larger ATT MTU negotiation for long JBL information responses.
- Pacing between request/response exchanges rather than treating a completed write as a completed command.
- Defensive parsing of fragmented, concatenated, repeated, malformed and unknown JBL frames.
- Correct setting-write coalescing: stale pending writes are removed before the newest command is queued.
- Multi-speaker discovery that does not stop after the first advertisement.
- Responsive controls for narrow displays and enlarged Android text.
- Copyable live diagnostic log.
- Optional experimental low-level AUX pilot, separated from BLE control.
- No generic DFU or firmware flashing.

## Current hardware status

Initial Charge 3 and Charge 4 testing exposed generation-specific Android BLE behaviour and directly informed test2. See [`docs/HARDWARE-TESTS.md`](docs/HARDWARE-TESTS.md).

Test2 still requires further real-hardware validation before it should be treated as a stable release.

## Build

Requirements:

- JDK 17
- Gradle 8.9 or a compatible Gradle installation
- Android SDK 35

```bash
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

The APK is generated at:

```text
app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions runs the same tests and build for pushes and pull requests targeting `main`.

## Safety

This software sends proprietary BLE control commands to supported JBL speakers. The current build deliberately excludes firmware-update commands. The AUX pilot is experimental and only affects audio generated by the Android device; it cannot disable analogue muting circuitry inside a speaker.
